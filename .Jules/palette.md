## 2024-05-18 - Localized ARIA Labels and Bootstrap 5 Data Attributes
**Learning:** Bootstrap components often rely on English defaults for things like `.btn-close` (e.g. "Close"). When localizing an application (in this case, pt-BR), it is critical to explicitly set `aria-label="Fechar"` on such elements so screen readers narrate the expected language. Additionally, ensure Bootstrap 5's data attributes follow the `data-bs-*` convention; specifically, closing alerts requires `data-bs-dismiss="alert"`, whereas older or misconfigured apps sometimes use invalid attributes like `data-bs-alert`.
**Action:** Always verify that Bootstrap close buttons have explicitly localized `aria-label` attributes and that JavaScript triggers use the standard `data-bs-dismiss` attribute to ensure proper behavior and accessibility.
