## 2024-05-18 - Localized ARIA labels and Bootstrap 5 Alert Dismissal
**Learning:** Found two important patterns in this app. First, `data-bs-alert` is an incorrect attribute for Bootstrap 5 alert dismissals; the correct attribute is `data-bs-dismiss="alert"`. Second, because this is a localized Portuguese app, default ARIA labels on utility components like `.btn-close` are absent and must be explicitly translated (e.g. `aria-label="Fechar"`) for screen readers. Similarly, icon-only buttons like the sidebar toggle `#sidebarCollapse` require an explicit `aria-label="Alternar menu"`.
**Action:** Always verify that Bootstrap 5 interactive data attributes (like `data-bs-dismiss`) are used instead of non-standard ones. When adding utility components (like close buttons) or icon-only buttons in localized applications, ensure ARIA labels are explicitly added and translated into the app's primary language.
