## 2026-08-20 - Adding ARIA labels in pt-BR
**Learning:** The application's UI is in Portuguese (pt-BR). Therefore, any accessibility enhancements like ARIA labels must be localized to Portuguese to match the context and user expectations.
**Action:** When adding ARIA labels to components without text (like icon-only buttons), ensure the text describes the action accurately in Portuguese, e.g., 'aria-label="Alternar menu lateral"' for a sidebar toggle.
