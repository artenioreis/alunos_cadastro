## 2026-08-22 - Translated ARIA Labels on Bootstrap Components\n**Learning:** Default Bootstrap components (like alert close buttons) lack accessible labels by default. In localized applications (like this pt-BR one), it's critical to override or provide these labels explicitly in the target language (e.g., `aria-label="Fechar"`) so screen readers don't fall back to English or remain silent on icon-only buttons.\n**Action:** Always inspect Bootstrap components for missing ARIA labels and ensure they are translated to match the app's primary language.
