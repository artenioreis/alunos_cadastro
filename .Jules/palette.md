## 2024-05-17 - Portuguese Screen Reader Optimization for Flash Messages
**Learning:** Bootstrap 5 alert dismiss buttons (`btn-close`) rely entirely on the `data-bs-dismiss` attribute to function and an `aria-label` to provide context for screen readers. In localized applications (like this Brazilian Portuguese app), using the default `aria-label="Close"` or completely omitting it makes it difficult for visually impaired users to understand the button's action. Additionally, incorrect `data-bs-*` attributes prevent the script from working correctly.
**Action:** When implementing flash messages or alert dismiss buttons in localized apps, explicitly add an `aria-label` in the target language (e.g., `aria-label="Fechar"`) to all `.btn-close` elements. Always verify that `data-bs-dismiss="alert"` is correctly used. Similar treatment should apply to other icon-only buttons, like menu toggles (`aria-label="Alternar menu"`).
